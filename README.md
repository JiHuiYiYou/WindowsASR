# 🎙️ Windows 实时语音转文字 (ASR) 工具

一款基于 Python 的 Windows 端实时语音识别工具，深度集成**阿里云智能语音交互**。本项目不仅仅是一个 Demo，而是采用了**大厂级音频流控与预处理架构**，旨在提供“顺风耳”般的精准、低延迟语音输入体验。

## ✨ 核心特性

*   **🎧 工业级音频处理**：内置 **VAD（静音检测）** 与 **动态 AGC（自动增益）**，有效过滤键盘声、风扇声等环境噪音。
*   **⚡ 高稳定流控**：采用**生产者-消费者模型**与**背压控制（Backpressure）**，即使网络波动也能保持音频流畅，拒绝程序假死。
*   **🏢 场景化识别**：针对**办公**（会议、代码、邮件）与**生活**（备忘、口语）双场景优化，支持阿里云热词与定制模型。
*   **🖥️ Windows 专属优化**：完美适配 Windows 声卡特性，自动处理位深转换，解决“能听但识别率低”的痛点。

1. 点击 **“▶ 开始录音”**。
2. 对着麦克风说话，识别结果将实时显示在文本框中。
3. 点击 **“■ 停止录音”** 结束会话。
